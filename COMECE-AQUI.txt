TELEGRAM ATENDIMENTO 4.0 — RENDER + SUPABASE

Esta versão separa a administração da biblioteca do uso diário no Telegram:

- dashboard/: painel web para cadastrar, organizar e ouvir áudios;
- extension/: extensão Chrome com somente uma barra compacta abaixo do campo de mensagem;
- server/: API do Render, conversão OGG/Opus, sessão Telegram e envio como voz;
- supabase/CONFIGURAR.sql: tabela de estado e bucket privado ta-media.

O dashboard usa o ACCESS_TOKEN e a extensão usa EXTENSION_PASSWORD. A chave secreta do
Supabase fica exclusivamente no Render. Não publique credenciais no GitHub.

COMECE PELO SUPABASE

1. Crie um projeto dedicado no plano Free.
2. Abra SQL Editor e execute todo o arquivo supabase/CONFIGURAR.sql.
3. Confirme que existe o bucket privado ta-media.
4. Copie Project URL e uma chave secreta de servidor para as variáveis do Render.

PUBLICAÇÃO DO BACKEND

Use o Blueprint render.yaml. Preencha SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY,
TELEGRAM_API_ID, TELEGRAM_API_HASH e EXTENSION_PASSWORD. Mantenha estáveis ACCESS_TOKEN e
SESSION_ENCRYPTION_KEY. Depois do deploy, copie a URL HTTPS do serviço.

PUBLICAÇÃO DO DASHBOARD

Crie um Static Site separado usando a pasta dashboard como Root Directory,
sem Build Command e com Publish Directory . Depois, coloque a URL completa
do dashboard na variável DASHBOARD_ORIGINS do serviço web do Render e publique
novamente a API. Para testar localmente, http://localhost:4173 já é aceito.

INSTALAÇÃO DA EXTENSÃO

1. Abra chrome://extensions e ative o Modo do desenvolvedor.
2. Clique em Carregar sem compactação e escolha a pasta extension.
3. Abra Opções da extensão e entre com EXTENSION_PASSWORD.
4. Abra ou atualize o Telegram Web e entre em uma conversa privada.
5. A barra aparecerá abaixo do campo de mensagem; use o deslizador e clique uma vez no nome do áudio.

No dashboard, use o cartão da conta Telegram para fazer o primeiro login
(telefone, código e senha 2FA). A extensão não tem mais painel lateral.

O guia detalhado está em INSTALACAO.md e em dashboard/README.md.
